# AGENTS.md — правила работы со Still

Инструкции для ChatGPT, Codex и других AI-агентов, которые работают с кодом Still.
Требования пользователя к конкретной задаче имеют приоритет.

## Контекст проекта

- Still — минималистичный список задач на React, TypeScript, Vite и CSS.
- Данные хранятся в `localStorage`, без backend, аккаунтов и синхронизации.
- Интерфейс на русском, со светлой и тёмной темами, шрифт Onest.
- Не добавляй даты, категории, уведомления и новые зависимости без запроса.

## Перед изменениями

1. Прочитай существующий код и проверь `git status` и `git diff`.
2. Не перезаписывай незакоммиченные изменения пользователя.
3. Выбери минимальное решение, сохраняющее текущую архитектуру и дизайн.
4. При необходимости сначала объясни, какие файлы будут затронуты.

## Код и качество

- Имена в коде на английском. Не добавляй комментарии в исходные файлы.
- Поддерживай доступность, адаптивность и `prefers-reduced-motion`.
- Не добавляй библиотеки ради простых CSS-эффектов.
- Корректно обрабатывай ошибки `localStorage`; не теряй данные молча.
- Не отправляй секреты, `.env`, `node_modules`, `dist` и временные файлы в Git.

## Проверки

Перед завершением изменения выполняй, когда окружение позволяет:

```bash
npm run lint
npm run format:check
npm run test
npm run build
```

Если проверка не выполнена, сообщи об этом прямо. Не называй непроверенное поведение рабочим.
Для Windows PowerShell при блокировке `npm.ps1` используй `npm.cmd`.

## Git и публикация

- Коммиты на английском в формате Conventional Commits, по смысловым изменениям.
- Не переписывай историю и не используй `git push --force`.
- Не коммить промежуточные эксперименты ради количества коммитов.
- Не отправляй изменения на GitHub и не разворачивай сайт без разрешения.
- Перед публикацией проверяй GitHub Actions; при ошибках исправляй причину, не отключай проверку.

## Документация

- README пиши по-русски и обновляй только по фактическому состоянию проекта.
- Указывай, что задачи сохраняются в браузере и не синхронизируются.
- Упоминание ChatGPT/Codex необходимо для тестового задания.
