# Still

Still — минималистичный веб-список задач на React, TypeScript и Vite.

## Возможности

- Создание, выполнение и удаление задач.
- Фильтры «Все», «Активные» и «Выполненные».
- Счётчик выполненных задач.
- Светлая и тёмная темы, адаптивный интерфейс и плавные анимации.
- Автоматическое сохранение задач в `localStorage`.

**Задачи сохраняются только в браузере текущего устройства и не синхронизируются между устройствами.** Серверная база данных и регистрация не требуются.

## Локальный запуск

Требуется Node.js 22.12+.

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. В Windows PowerShell при блокировке `npm.ps1` используйте `npm.cmd`.

## Проверки

```bash
npm run lint
npm run format:check
npm run test
npm run build
```

Production-сборка появляется в `dist/`.

## Размещение через Docker

```bash
docker compose up -d --build
```

Сайт будет доступен **только на самом сервере** по адресу `http://127.0.0.1:18080`. Для публичного HTTPS-адреса нужно настроить существующий reverse proxy на этот порт и выпустить сертификат для домена. Это отдельный контейнер; конфигурацию VPN или других сервисов менять не требуется.

`Dockerfile` собирает статику Vite и обслуживает её через Nginx. Dev-сервер не используется в production.

## Использование AI

При разработке использовались ChatGPT и Codex для проработки интерфейса, помощи с кодом и проверок. Итоговые решения и результат проверяются автором проекта.
