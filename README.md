# Still

Минималистичный список повседневных задач. Только необходимое — без аккаунтов,
сложных настроек и лишних элементов интерфейса.

**[Открыть Still](https://still.31-76-77-123.sslip.io/)**

## Возможности

- Добавление, выполнение и удаление задач.
- Фильтрация: «Все», «Активные», «Выполненные».
- Счётчик выполненных задач.
- Светлая и тёмная темы с сохранением выбора.
- Адаптивный интерфейс для компьютера и телефона.
- Плавные анимации с поддержкой `prefers-reduced-motion`.
- Автоматическое сохранение задач в браузере.

Данные хранятся в `localStorage` на текущем устройстве. Синхронизации между
браузерами и устройствами нет. Регистрация, серверный API и база данных не нужны.

## Технологии

**React 19 · TypeScript · Vite 8 · CSS · localStorage**

Приложение собирается в статические файлы и не требует backend.

## Локальный запуск

Необходимы **Node.js 22.12+** и npm.

```bash
git clone https://github.com/KULICHx/still-todo.git
cd still-todo
npm ci
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://127.0.0.1:5173`).

## Проверка проекта

```bash
npm run lint
npm run format:check
npm run test
npm run build
```

Сборка для публикации создаётся в папке `dist/`. Те же проверки автоматически
запускаются в [GitHub Actions](https://github.com/KULICHx/still-todo/actions).

## Развёртывание

Для production используется **Nginx в Docker**. Собрать и запустить контейнер
можно без Docker Compose:

```bash
docker build -t still-todo .
docker run -d --name still-todo --restart unless-stopped \
  -p 127.0.0.1:18080:80 still-todo
```

Если установлен Docker Compose, вместо этих команд можно выполнить:

```bash
docker compose up -d --build
```

Контейнер принимает запросы на `127.0.0.1:18080` сервера. Публичный HTTPS
обеспечивается отдельным reverse proxy (на действующем сайте — Caddy).
Vite dev-сервер в production не используется.

## Использование AI

При разработке использовались **ChatGPT и Codex**: для проработки интерфейса,
помощи с реализацией, анализа кода и подготовки проверок. Качество результата
контролируется автоматическими тестами, линтером и production-сборкой.
AI не используется при работе самого приложения.
