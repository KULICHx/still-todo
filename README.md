# Still

Минималистичный список задач на React и TypeScript. Проект создаётся последовательно для тестового задания: каждый законченный этап оформляется отдельным коммитом.

## Текущий этап

Подготовлена основа React + TypeScript + Vite, строгая проверка типов, ESLint и Prettier. Приложение запускается и показывает стартовый экран. Функциональность задач ещё не реализована.

## Запуск

Нужны Node.js 22.12+ и npm.

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite.

## Проверки

```bash
npm run lint
npm run format:check
npm run build
```

`npm run build` проверяет типы и создаёт production-сборку в `dist`. Для просмотра сборки используйте `npm run preview`.

## Планируемые возможности

- Добавление, выполнение и удаление задач.
- Сохранение задач после обновления страницы.
- Фильтры и счётчики.
- Светлая и тёмная темы с лавандовым акцентом.
- Адаптивный интерфейс и управление с клавиатуры.

## Разработка

Интерфейс и идентификаторы — на английском, документация — на русском. Исходный код без комментариев. Зависимости зафиксированы в `package-lock.json`.

Коммиты: `type(scope): description`. Новая функциональность — `feat`, исправления — `fix`, переработка без изменения поведения — `refactor`, тесты — `test`, документация — `docs`, инструменты — `chore`. Тип `style` используется только для форматирования кода.

Одна логическая задача — один коммит после соответствующих проверок. Функциональность и несвязанные исправления не объединяются.
